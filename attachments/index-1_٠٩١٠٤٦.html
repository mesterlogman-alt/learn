ترجمة Gemini

Gemini هنا للترجمة فقط: ترجمة الجمل + معنى كل كلمة. كل التصنيف والحفظ والعمل دون اتصال يتم محليًا داخل التطبيق.

1) النص المصدر

استورد TXT أو PDF أو الصق النص. سيقسّم التطبيق النص تلقائيًا إلى طلبات صغيرة قبل إرسالها.

TRANSLATION ONLY
لم يتم اختيار ملف
مصدر الترجمة: لا يوجد نص بعد. اكتب نصًا أو اختر ملفًا.
الأحرف: 0 الكلمات: 0 الجمل: 0 الطلبات المتوقعة: 0

2) إعداد الترجمة

لا توجد أدوات تحليل أو ترجمة إضافية. التطبيق يرسل أقل بيانات لازمة للترجمة فقط.

لم يتم إدخال مفتاح بعد.
النموذج الافتراضي: Gemini 3.5 Flash-Lite. نموذج احتياطي داخلي: Gemini 3.6 Flash.

3) التنفيذ

جاهز. بعد الاكتمال: تصنيف الكلمات محليًا → حفظ المشروع → تشغيل أوفلاين.

جاهز
لم تبدأ ترجمة Gemini بعد.
✓ Gemini يترجم الجمل ومعاني الكلمات فقط
✓ الطلبات صغيرة ومقسمة حسب الحجم الفعلي
✓ كل نتيجة تُراجع قبل قبولها
✓ إعادة المحاولة مع تأخير تدريجي عند الفشل
✓ الاحتفاظ بالتقدم الناجح لاستكماله بعد الفشل
✓ التصنيف والحفظ محليان ولا يستهلكان مفتاح Gemini
